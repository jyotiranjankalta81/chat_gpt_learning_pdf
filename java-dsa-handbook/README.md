## How to Use This Handbook

### For a 5-Year Experienced Engineer

You already understand software systems deeply. Leverage that:

- **Redis knowledge** → understand hash maps, LRU cache
- **Kafka knowledge** → understand queues, priority queues, streams
- **Docker/K8s** → understand graphs, topological sort (dependency resolution)
- **Terraform** → understand trees (resource dependency graphs)
- **AWS Lambda** → understand recursion and event-driven decomposition

### Study Order (Recommended)

```
Week 1: Section 1 (Java Syntax Review) + Section 2 (Collections) + Section 3 (Foundations)
Week 2: Section 4 Patterns 1-7 (Sliding Window → Trees)
Week 3: Section 4 Patterns 8-15 (Graphs → Bit Manipulation)
Week 4: Section 5 (Interview Prep) + Section 6 (Roadmap Execution) + Mock Interviews
```

### Quick Start

If you're short on time, start with [CheatSheets/pattern-recognition.md](./CheatSheets/pattern-recognition.md) to immediately identify which pattern applies to a problem, then deep-dive into the relevant section.

## Key Philosophy

> **"Every interview problem is a disguised pattern. Your job is to unmask it."**

The 3-step framework for every problem:
1. **Recognize** — Which pattern does this belong to?
2. **Recall** — What is the template for this pattern?
3. **Adapt** — How do I modify the template for this specific problem?
