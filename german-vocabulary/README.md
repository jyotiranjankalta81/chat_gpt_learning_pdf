## Table Column Guide

Each vocabulary table uses the following columns:

| Column | Description |
|--------|-------------|
| **#** | Entry number |
| **German** | The German word or phrase |
| **English** | English meaning |
| **Pronunciation** | English phonetic approximation |
| **Article** | der / die / das (nouns only) |
| **PoS** | Part of speech |
| **Example (DE)** | German example sentence |
| **Example (EN)** | English translation |
| **Context** | Primary usage context |
| **Plural / Conj.** | Plural form (nouns) or conjugation basics (verbs) |
| **Collocations** | Common word combinations |
| **Synonyms** | Important synonyms |
| **Opposites** | Useful antonyms |

## CEFR Level Descriptions

| Level | Name | Description |
|-------|------|-------------|
| **A1** | Beginner | Basic survival phrases, greetings, numbers, simple daily needs |
| **A2** | Elementary | Simple conversations, travel, shopping, basic past tense |
| **B1** | Intermediate | Work, health, news topics, opinions, connected speech |
| **B2** | Upper-Intermediate | Professional settings, complex opinions, nuanced language |
| **C1** | Advanced | Near-native fluency, technical fields, abstract topics, idioms |

## Key Learning Priorities

1. **Spoken German first** — all vocabulary chosen for conversational use
2. **Germany workplace communication** — office, meetings, emails
3. **Daily integration vocabulary** — banking, renting, healthcare, transport
4. **Technical and professional** — Cloud, DevOps, AI, software engineering
5. **Natural conversational fluency** — collocations, idioms, register
